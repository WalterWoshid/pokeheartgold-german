# Pokémon HeartGold and SoulSilver (German)

This fork adds matching German HeartGold and SoulSilver builds to [pret/pokeheartgold](https://github.com/pret/pokeheartgold). Both German revision 0 ROMs rebuild from editable source assets.

See [GERMAN.md](GERMAN.md) for German build instructions, source editing, and the Windows WSL helper, or [INSTALL.md](INSTALL.md) for build dependencies.

> ![WARN]
> Because this ROM is not fully decompiled, modifications that affect the size or layout of any function or data structure can result in a game crash.
